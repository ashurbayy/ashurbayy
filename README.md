## Selected projects

### NeuroTwin-IR

A research-stage brain MRI platform developed for TEKNOFEST 2026. The project connects MRI upload, tumor segmentation review, 3D visualization, scenario exploration, and structured PDF reporting in one workspace.

- **Imaging:** T1, T1CE, T2, and FLAIR workflows with WT / TC / ET region review.
- **Visualization:** multiplanar MRI views and 3D tumor representations.
- **Digital twin:** baseline anatomy and standardized 30 / 60 / 90-day scenario exploration. Scenarios are not validated patient-specific forecasts.
- **Reporting:** analysis-linked reports with Azerbaijani, Turkish, and English output.

Research use only; not a diagnostic system or treatment recommendation engine. Implementation, model weights, and imaging data remain private.

### [LifeChip](https://github.com/ashurbayy/lifechip)

A full-stack web prototype exploring emergency health-information access and an NFC-linked profile concept. The repository includes a React interface, account and profile pages, an Express backend, and shared TypeScript schemas.
